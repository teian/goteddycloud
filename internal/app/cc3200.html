Flash a CC3200 Toniebox

Use an ESP32-C3 with native USB as a UART gateway. This workflow backs up the box before installing the HackieboxNG preloader and teddyCloud replacement CA.

Hardware acceptance is pending. Keep an independent backup, use stable power, and keep the browser open during writes. USB access requires a Web Serial browser and HTTPS or localhost.

1. Prepare the gateway and wiring

Install the ESP32-C3 gateway firmware, then disconnect that tool to release the USB port. This page configures the gateway when connecting.

Connect common GND, gateway TX → box RX, gateway RX → box TX, reset GPIO → box RST, control GPIO → box SOP2. Use 3.3 V logic; never connect 5 V to the box. Check your board’s pinout before connecting.

CC3200 pinout · Gateway reference

The loader is checked against a pinned SHA-256 before upload to SRAM. CC3200 ROM revisions below 4 require the legacy tool.

2. Back up flash and files

Read and compare the complete serial flash twice, then read every named file twice. Unnamed and mirrored allocations are preserved by ID. Important files missing from the FAT are also queried directly by name.

Backups include private certificate keys. The ZIP is stored in the selected filesystem/S3 backend under the firmware directory.

3. Review and install

Get a HackieboxNG release and extract it first. The preloader is a different file from your box’s original mcuimg.bin.

The hash must independently identify your original bootloader, or an already preserved /sys/pre-img.bin. Structural checks alone do not identify an official release.

The original bootloader is preserved in /sys/pre-img.bin first, followed by /cert/c2.der. The preloader replaces /sys/mcuimg.bin last. Every write is read back and compared.

4. Finish setup

After successful verification, disconnect, remove programming wiring and restart the box. Configure the SD bootloader’s altCA.305 and URL patches for your teddyCloud address.

For firmware 3.1.0 BF2, 3.3.0 or 3.4.0, copy this file to revvox/boot/patch/altPort.json on the microSD and enable altPort in ngCfg.json for the selected original firmware. API and RTNL connections use this port with TLS. Your proxy must forward it to the box TLS listener. Port 8443 is normally the web UI; keep it separate. To return to 443, disable the patch or generate it with port 443.
